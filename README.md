# Assignment 2 : E-Commerce Product App with Pagination and Cart State (Frontend)

Ứng dụng Expo React Native đáp ứng đầy đủ yêu cầu Assignment 2.

## Khởi chạy

```powershell
npm install
npm start
```

- Phím `w` mở trên trình duyệt Web.
- Quét mã QR bằng Expo Go trên iOS / Android để trải nghiệm trên điện thoại.

## Các màn hình chính
- `ProductListScreen.js` (src/Screens/ProductListScreen.js)
- `ProductDetailScreen.js` (src/Screens/ProductDetailScreen.js)
- `CartScreen.js` (src/Screens/CartScreen.js)

## Các Atomic Components
- `ProductCard.js` (src/Components/ProductCard.js)
- `CartItem.js` (src/Components/CartItem.js)
- `PriceSummary.js` (src/Components/PriceSummary.js)
